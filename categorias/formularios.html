Área de texto largo (textarea)

Campo que permite escribir textos largos como comentarios o mensajes.

Sintaxis

<textarea></textarea>

Ejemplo práctico

Se utiliza cuando el usuario necesita escribir más información.

Buenas prácticas

Usar atributos como rows, cols o maxlength.

Botón de acción (button)

Elemento que ejecuta acciones dentro del formulario.

Sintaxis

<button type="tipo">Texto</button>

Ejemplo práctico

El atributo type define el comportamiento del botón.

Buenas prácticas

Usar texto claro para indicar la acción del botón.
