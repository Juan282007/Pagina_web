ul

Lista desordenada (viñetas)

Sintaxis básica

<ul> <li>Elemento</li> </ul>

Ejemplo práctico funcional

  • Manzana
  • Banana
  • Naranja

Uso correcto: agrupar elementos sin un orden específico

Buenas prácticas

  • Siempre debe contener elementos li.
  • No usar para diseño visual.

ol

Lista ordenada (numerada)

Sintaxis básica

<ol> <li>Elemento</li> </ol>

Ejemplo práctico funcional

  1. Paso 1
  2. Paso 2
  3. Paso 3

Uso correcto: cuando el orden de los elementos es importante

Buenas prácticas

  • Usarla solo cuando el orden tenga significado.

li

Elemento de lista (ul, ol o dl)

Sintaxis básica

<li>Elemento</li>

Ejemplo práctico funcional

  • Elemento de lista

Uso correcto: siempre dentro de ul, ol o dl

Buenas prácticas

  • No usar fuera de una lista.

dl

Lista de definiciones

Sintaxis básica

<dl> <dt>Término</dt> <dd>Descripción</dd> </dl>

Ejemplo práctico

HTML
Lenguaje de marcado
CSS
Estilos de página web

Uso correcto: agrupar términos y sus definiciones

Buenas prácticas

  • Usar solo para términos y definiciones reales.

dt

Representa el término dentro de una lista de definiciones

Sintaxis básica

<dt>Término</dt>

Ejemplo práctico funcional

HTML
Lenguaje de marcado

Uso correcto: siempre junto con dd dentro de dl

Buenas prácticas

  • No usar fuera de dl.
