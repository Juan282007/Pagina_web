img

Muestra una imagen en la página web.

Sintaxis básica

<img src="imagen.jpg" alt="Descripción">

Ejemplo práctico

Explicación

El atributo src indica la ruta de la imagen y alt describe la imagen.

Buenas prácticas

  • Siempre agregar el atributo alt.
  • Optimizar el tamaño de la imagen.

audio

Permite reproducir sonido.

Sintaxis básica

<audio controls> <source src="audio.mp3" type="audio/mpeg"> </audio>

Ejemplo práctico

Explicación

El atributo controls muestra los botones de reproducción.

Buenas prácticas

  • Usar el formato correcto (mp3).
  • Siempre incluir controls.

video

Permite reproducir videos.

Sintaxis básica

<video controls> <source src="video.mp4" type="video/mp4"> </video>

Ejemplo práctico

Explicación

Se puede definir el tamaño con width y usar controls para mostrar los botones.

Buenas prácticas

  • Usar formato mp4 para mayor compatibilidad.
  • Definir tamaño adecuado.

iframe

Permite mostrar otra página o contenido externo dentro del sitio.

Sintaxis básica

<iframe src="pagina.html"></iframe>

Ejemplo práctico

Explicación

Se usa para insertar mapas, videos o páginas externas.

Buenas prácticas

  • Definir width y height.
  • Usarlo solo cuando sea necesario.
