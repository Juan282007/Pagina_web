Imagen (img)

Permite mostrar una imagen en la página web.

Sintaxis básica

<img src="imagen.jpg" alt="Descripción">

Ejemplo práctico

Explicación

El atributo src indica la ruta de la imagen y alt describe la imagen para accesibilidad y SEO.

Buenas prácticas

  • Siempre agregar el atributo alt.
  • Optimizar el tamaño de la imagen para mejorar la carga de la página.
  • Usar formatos compatibles como jpg, png o webp.

Audio

Permite reproducir sonido en la página web.

Sintaxis básica

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>

Ejemplo práctico

Explicación

El atributo controls agrega botones para reproducir, pausar y controlar el volumen.

Buenas prácticas

  • Usar el formato correcto (mp3 o ogg) para compatibilidad.
  • Siempre incluir controls para que el usuario pueda reproducir el audio.
  • Proporcionar texto alternativo o transcripción si el audio es importante.

Video

Permite reproducir videos en la página web.

Sintaxis básica

<video controls>
  <source src="video.mp4" type="video/mp4">
</video>

Ejemplo práctico

Explicación

Se puede definir el tamaño con width y usar controls para mostrar los botones de reproducción.

Buenas prácticas

  • Usar formato mp4 para mayor compatibilidad con navegadores.
  • Definir tamaño adecuado y proporción correcta.
  • Incluir subtítulos con <track> para accesibilidad.

Iframe

Permite mostrar otra página o contenido externo dentro del sitio.

Sintaxis básica

<iframe src="pagina.html"></iframe>

Ejemplo práctico

Explicación

Se usa para insertar mapas, videos, documentos o páginas externas. El atributo title ayuda a los lectores de pantalla.

Buenas prácticas

  • Definir width y height para mantener proporciones y diseño.
  • Usarlo solo cuando sea necesario para contenido externo.
  • Agregar atributo title para accesibilidad.
  • Evitar el uso excesivo de iframes por temas de seguridad y SEO.
