Etiquetas de Tablas

Inicio

table

Define una tabla en HTML.

Sintaxis básica

<table> Contenido </table>

Ejemplo práctico

Nombre Edad
Juan 20

Explicación

Se usa para organizar información en filas y columnas.

Buenas prácticas

  • Usar tablas solo para datos, no para diseño.
  • Mantener estructura ordenada.

tr

Define una fila dentro de la tabla.

Sintaxis básica

<tr>Fila</tr>

Ejemplo práctico

Fila 1

Explicación

Cada fila agrupa celdas (td o th).

Buenas prácticas

  • Debe ir dentro de table.

td

Define una celda de datos.

Sintaxis básica

<td>Dato</td>

Ejemplo práctico

Dato

Explicación

Contiene la información de la tabla.

Buenas prácticas

  • Debe ir dentro de tr.

th

Define una celda de encabezado.

Sintaxis básica

<th>Encabezado</th>

Ejemplo práctico

Nombre Edad

Explicación

Se usa para los títulos de columnas o filas.

Buenas prácticas

  • Usarlo en la primera fila.
  • Facilita la lectura de la tabla.
