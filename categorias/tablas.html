Contenedor de datos tabulares (table)

Elemento que crea una estructura de tabla con filas y columnas.

Sintaxis

<table>Contenido de la tabla</table>

Ejemplo práctico

Nombre Edad
Juan 20

Buenas prácticas

  • Usar tablas solo para datos y no para diseño.
  • Agregar caption para describir la tabla.
  • Usar thead, tbody y tfoot para estructurar la tabla.
  • Evitar atributos de presentación como border, usar CSS en su lugar.

Fila de tabla (tr)

Elemento que representa una fila dentro de una tabla.

Sintaxis

<tr>Contenido de la fila</tr>

Ejemplo práctico

Fila 1 Fila 1 columna 2

Buenas prácticas

  • Debe utilizarse dentro de table, thead, tbody o tfoot.
  • Asegurarse de que todas las filas tengan el mismo número de celdas por accesibilidad.

Celda de datos (td)

Elemento que contiene información dentro de una tabla.

Sintaxis

<td>Dato</td>

Ejemplo práctico

Producto Precio
Mouse $20

Buenas prácticas

  • Debe ir dentro de una fila tr.
  • Evitar celdas vacías; si es necesario, usar  .
  • Usar scope en th para accesibilidad.

Celda de encabezado (th)

Elemento que define el título de una columna o fila.

Sintaxis

<th>Encabezado</th>

Ejemplo práctico

Nombre Edad Ciudad
Ana 19 Neiva

Buenas prácticas

  • Usarlo en la primera fila o columna para identificar datos.
  • Agregar scope="col" o scope="row" para accesibilidad.
  • Evitar usar th solo por negrita; usar CSS para estilos.

Título descriptivo de tabla (caption)

Elemento que agrega un título o descripción a la tabla.

Sintaxis

<caption>Título de la tabla</caption>

Ejemplo práctico

Lista de Estudiantes
Nombre Edad
Ana 19

Buenas prácticas

  • Colocarlo inmediatamente después de table.
  • Describir claramente el contenido de la tabla para usuarios y lectores de pantalla.

Encabezado estructural de tabla (thead)

Elemento que agrupa las filas de encabezado de la tabla.

Sintaxis

<thead><tr><th>Título</th></tr></thead>

Ejemplo práctico

Producto Precio
Teclado $30

Buenas prácticas

  • Siempre usar thead para separar el encabezado del cuerpo.
  • Usar th dentro de thead con scope.

Cuerpo de la tabla (tbody)

Elemento que agrupa las filas con datos principales.

Sintaxis

<tbody><tr>Datos</tr></tbody>

Ejemplo práctico

Libro $10
Cuaderno $5

Buenas prácticas

  • Separar claramente el cuerpo de los encabezados.
  • Usar tbody aunque la tabla no tenga thead para consistencia.

Pie de tabla (tfoot)

Elemento que define la parte final de la tabla, usualmente para totales o resúmenes.

Sintaxis

<tfoot><tr>Resumen</tr></tfoot>

Ejemplo práctico

Producto Precio
Producto A $20
Producto B $15
Total $35

Buenas prácticas

  • Usar tfoot para totales o notas finales.
  • Colocarlo antes de tbody en HTML si se desea que los navegadores lo rendericen al final.
  • Agregar scope y accesibilidad para celdas resumen.
