<p>

Definición

    La etiqueta p se usa para crear párrafos.

Sintaxis

<p>Texto</p>

Ejemplo práctico

Este es un párrafo real.

Se usa para organizar el contenido en bloques de texto.

Buenas prácticas

  • No usar p para títulos
  • No usar p vacío

strong

Definición

    Se usa para dar importancia al texto.

Sintaxis

<p>Texto con <strong>énfasis fuerte</strong></p>

Ejemplo práctico

Este texto es importante

Establecer una importancia a una palabra o fragmento de texto que consideremos importante.

Buenas prácticas

  • No usar solo para negrita visual.

Título Principal
