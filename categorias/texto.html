Etiquetas de Texto

Inicio

<p>

Definición

La etiqueta p se usa para crear párrafos.

Sintaxis

<p>Texto</p>

Ejemplo práctico

Este es un párrafo real.

Explicación

Se usa para organizar el contenido en bloques de texto.

Buenas prácticas

  • No usar p para títulos
  • No usar p vacío
