header

Define el encabezado de la página

Sintaxis

<header>Contenido del encabezado</header>

Ejemplo práctico

Uso correcto: Se usa para colocar el logo, título o menú principal.

Buenas prácticas

No usarlo solo como contenedor visual. Debe contener información introductoria.

nav

Define el menú de navegación

Sintaxis

<nav>Enlaces</nav>

Ejemplo práctico

Inicio | Contacto

Se usa para menús principales o secundarios.

Buenas prácticas

Usar solo para enlaces importantes.

main

Representa el contenido principal del documento

Sintaxis

<main>Contenido principal</main>

Ejemplo práctico

Zona principal de la página

Debe existir solo una vez por página.

Buenas prácticas

No incluir contenido repetido.

section

    Agrupar contenido

Sintaxis

<section>Contenido</section>

Ejemplo

Sección informativa

Divide el contenido por temas.

Buenas prácticas

Debe contener encabezado

footer

Pie de página

Sintaxis

<footer>Pie</footer>

Ejemplo

Pie

Contiene información final.

Buenas prácticas

Incluir información de contacto o derechos.
